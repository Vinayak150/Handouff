# Open-source license release gate

**Status: contributor rights UNVERIFIED; no license granted by this document.**

This public repository holds the reconstructed HandoffGuard reference, not a verified export of the original cohort implementation. Public GitHub visibility does not itself license reuse. WUNDERDEVS must decide an SPDX-listed license (MIT is an option only after affirmative rights confirmation), record each contributor's approval, check third-party code/data provenance and verify the historical cohort's terms before creating a root `LICENSE` file.

| Required evidence | Record |
|---|---|
| Code owners and contributors | NOT SUPPLIED |
| Rights to distribute/relicense each included source file | NOT CONFIRMED |
| Prior cohort code copyright and license | NOT RETRIEVED |
| Third-party dependency and asset review | NOT SIGNED OFF |
| Team's selected OSI-approved license and full text | NOT APPROVED |
| Signoff date and approving team member(s) | NOT PROVIDED |

Do not add a purported MIT or other final license without these approvals. The absent `LICENSE` is a submission blocker, not a test failure.
